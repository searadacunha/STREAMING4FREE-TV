# IPTV4FREE official logo

The exact user-provided, blue-and-white IPTV4FREE globe/orbit/stars PNG belongs here as `IPTV4FREE-original.png`. **It has not yet been uploaded**, because the image attachment binary could not be transferred from the conversation environment to GitHub. Do not replace it with generated or traced artwork.

Upload by selecting **Add file → Upload files** in this directory on branch `feat/iptv4free-tv-ui`, and name the original file exactly `IPTV4FREE-original.png`. Then GitHub Actions packages the branded add-on automatically. For local building, install `pillow` and run `python3 scripts/build_addon.py`.

Generated outputs inside Kodi add-on: `icon.png` (square 512×512 transparent aspect-fit icon) and `resources/skins/Default/media/iptv4free-logo.png` (byte-identical artwork). The icon is referenced by `addon.xml`, and the full logo is displayed by the home interface when available.
